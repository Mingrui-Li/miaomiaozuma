# 难度递进与无限广告复活

决策日期：2026-09-07。项目所有者已确认难度/尺寸调整，明确要求广告复活不设单局次数上限。本文件不代表几何、ImageGen 或 Figma 验收通过。

## 1. 已冻结的运营规则

- 第 1～5 关：五猫、首局受控爽点和一次免费复活，不调用复活广告。
- 第 6～100 关：每次主动完整观看一条有效激励广告，获得一次复活；同一局可以重复，游戏不设次数上限。
- 每次复活继续当前局，不清空本局进度；沿用 GDD 的退链与清理末端三只猫奖励，不能随次数增加暗中缩水。
- 不自动播放广告，不伪造完成回调；失败、取消或无填充不发放奖励。免费重开、返回地图一直存在。
- 广告次数不限不等于平台供应无限；资源不可用时给出真实提示与重试/重开路径。
- 同一次广告完成只发奖一次；新一次有效广告完成可再次发奖。复活次数不能充当布尔开关或幂等标识。
- 活动局长 60～120 秒是未含广告和多次复活的基准目标；无限复活可能延长真实会话，广告耗时另计。

## 2. 难度不是轨道长度

旧候选按长度排序的做法已否决。轨道更长还可能给玩家更多缓冲时间，不能推断更难。后续几何必须同时标出：

1. 同一射线穿过两层/三层轨道的角度范围。
2. 猫链占用这些层后，远目标被遮挡的比例及位置。
3. 哪一处近组清除能打开哪一处远组的窗口。
4. 队首进入末段时，从哪个方向救场，是否需要先处理近层。
5. 有效操作后打开的机会，而不是不可解的永久遮挡。

以上仍只是几何压力指标，不是玩家通关率。生成计划、障碍、速度、帮助度和真实操作测试完成后才能确认实际难度。

## 4. 百关难度区间

通关率为目标玩家首次尝试、无道具、无复活的初始调优目标，不是行业标准、模拟结果或已测数据。通过过往关卡的玩家群体必须单独统计，不能与首次接触游戏的人混比。

| 关卡 | 主要空间挑战 | 首尝通关率调优区间 |
|---|---|---:|
| 1～5 | 直接匹配、方位切换、少量回折；五猫和核心爽点优先 | 85%～95% |
| 6～20 | 局部双层、近远目标选择；11 关起加入纸箱 | 75%～85% |
| 21～40 | 双层嵌套、揭示后补位、接缝打开远层 | 60%～75% |
| 41～60 | 紧凑多层、连续回折，与速度波/障碍组合 | 50%～65% |
| 61～80 | 多处遮挡、局部三层、短暂穿缝窗口与末端救场 | 40%～55% |
| 81～100 | 多区交替遮挡、局部三层与连锁规划综合 | 30%～50% |

每章安排缓和与挑战，整体递进，不要求每一关都比上一关更难。五猫、障碍出现章节、三道具、单入口单终点无分叉规则保持不变。

## 5. 每关审核卡

必须包含关卡号、几何源哈希、尺寸档、入口/老巢坐标与朝向、轨道样条、两层/三层角覆盖、固定猫链快照、开缝前后同一射线、末段救场方向、本关训练目标和验收状态。

几何形态的 RMS 去重仍是复审工具，但不能主导选关；相似度低而没有新决策也不算设计成功。不得再次仅按长度/新奇度生成并宣布百关完成。

## 6. 验证与运营观察

- 难度：首尝/重试通关率、失败路程位置、无操作缓冲秒数、卡关次数、失败后直接退出率。
- 复活：展示、选择、加载、完整观看、取消、错误、发奖成功、复活次数、复活后活动时长、最终通关。
- 留存：次日与后续回访，以及不同难度/复活次数群体的流失；不只看单次会话的广告次数。
- 回归：同局 2/10/100 次复活；每次只有一个广告请求；同会话重复回调、旧局迟到回调、断网、切后台。
- 当前仍只做几何设计与文档；这些运行与运营验收没有完成，不授权 Cocos 重构。
