## 复现

必须使用新的真实 `/private/tmp/...` 路径，不能覆盖旧证据或用`/tmp`别名。例：

```bash

```

以Creator CLI或该临时工程构建面板读取其`build-config.json`。完成后运行对应的`tools/ui-flow/finalize-build.py`或`tools/ui-catalog/finalize-build.py`，补齐许可证并隐藏默认性能浮层；不要删演示标识。
