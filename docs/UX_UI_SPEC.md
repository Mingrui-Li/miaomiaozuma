## 1. 视觉方向

关键词：软糖猫咪、奶油色纸箱、圆润木牌、暖阳庭院、柔软高光、粗轮廓、高对比花纹、轻微手作感。

禁止方向：写实照片、廉价塑料 3D、过度粉红、婴幼儿风、赛博霓虹、复杂国风纹样、恐怖表情、爆炸伤害表现。

### 1.1 建议色板

| Token | 色值 | 用途 |
|---|---|---|
| `color.bg.sky` | `#BFE9F4` | 主背景天空 |
| `color.bg.cream` | `#FFF4D8` | 卡片与面板 |
| `color.bg.grass` | `#B9D982` | 地面与地图 |
| `color.ink.primary` | `#4B382F` | 主文字和粗描边 |
| `color.ink.secondary` | `#7A6254` | 次文字 |
| `color.brand.orange` | `#FF9F43` | 主按钮、橘猫 |
| `color.brand.coral` | `#FF6F61` | 强调、危险但不恐怖 |
| `color.brand.mint` | `#72D6B5` | 成功、进度 |
| `color.brand.blue` | `#70B7E6` | 蓝猫、信息 |
| `color.brand.purple` | `#8467B3` | 玄猫、呼噜能量 |
| `color.white` | `#FFFFFF` | 高光与反白文字 |
| `color.disabled` | `#C9C1B8` | 禁用状态 |

实际 Figma 写入前先检查现有变量；只有没有适合令牌时才创建以上本地变量。

### 1.2 字体

- 中文首选系统可用的圆体/黑体，以 Figma 和 Cocos 均能合法使用为准。
- 正文必须保证简体中文完整字形，不能依赖仅含拉丁字符的展示字体。
- 标题可使用经过授权的圆润字体资源；未确认授权前使用系统黑体作为开发基线。
- Figma 写入前必须枚举可用字体，不猜测字体样式名。

字号基线：标题 48、页面标题 36、主要按钮 34、正文 28、辅助 24、角标 20。所有数值是 750 宽设计尺寸。

### 1.3 尺寸令牌

- 间距：8、16、24、32、48、64。
- 圆角：16、24、36、48、全圆。
- 描边：普通 4px，聚焦/主按钮 6px。
- 阴影：Y=8、Blur=0～12、透明度 18%～25%，偏手作而非真实悬浮。
- 最小点击热区：88 × 88。
- 主按钮：宽 420～520，高 96。

## 2. 游戏主场景布局 P04

### 2.1 区域划分

| 区域 | Y范围 | 内容 |
|---|---:|---|
| 顶部安全区 | 0～88 | 仅背景，不放核心按钮 |
| HUD | 88～230 | 暂停、关卡、目标进度、小鱼干/分数 |
| 玩法区 | 190～1160 | 唯一入口、连续轨道、猫链、中央发射器、唯一老巢、局内特效 |
| 底部道具区 | 1160～1260 | 三个道具；不得占用中央发射器或轨道端点 |
| 底部安全区 | 1260～1334 | 背景和手势避让 |

### 2.2 视觉层级

1. 当前发射猫与瞄准线。
2. 轨道上可匹配的猫咪。
3. 靠近终点的危险提示。
4. 呼噜槽。
5. 道具和次要数值。

轨道必须与背景分离：使用奶油色/木色实线或脚印带，不依靠阴影独自表达路径。猫咪不得被草地、花朵等装饰遮挡。

入口、老巢和发射器必须一眼可区分：入口只接轨道起点，老巢只有一个洞口且只接轨道终点，发射器固定在玩法区几何中心。轨道脚印箭头全部指向老巢。

### 2.3 瞄准交互

- 在非 UI 玩法区按下或滑动进入瞄准；初始方向从中央发射器指向触点，允许 360° 连续旋转。
- 拖动实时更新瞄准线和预测碰撞点。
- 松开发射；手指回到发射器 48px 范围内松开视为取消。
- 发射期间当前猫位变空，下一只猫补到当前位并播放 0.16 秒弹性动画。
- 点击发射器中央交换当前/下一只；拖动距离超过 16px 后不再判为点击。

### 2.4 危险反馈

- 队首进入轨道最后 25%：终点仓库轻微晃动，轨道末段变珊瑚色。
- 最后 10%：每 1.2 秒一次柔和警示脉冲；不使用刺耳警报。
- 进入最后 5%：猫咪出现紧张表情，呼噜槽边缘加亮。

## 3. 页面规格

### P00 启动/合规

- 中央 Logo 和五只猫剪影依次亮起。
- 底部加载条显示真实进度，不能假进度卡住。
- 首次进入显示健康游戏忠告；后续按平台要求展示。
- 加载错误提供“重试”，离线可进入时提供“离线进入”。

### P01 主界面

- 中央为选中的主猫和游戏标题。
- 主按钮“继续第 N 关”位于下半屏拇指舒适区。
- 小鱼干在顶部左侧；设置在顶部右侧并避让平台胶囊。
- 底部三个次入口：关卡、图鉴、外观。
- 不出现弹窗式广告入口。

### P02 关卡地图

- 100 个脚印节点按十个章节分段，可纵向滚动。
- 当前关自动滚动到屏幕中部。
- 节点显示关卡号和历史星级；锁定节点降低饱和度并显示小锁。
- 点击已解锁节点进入 P03；锁定节点弹 Toast，不打开弹窗。

### P03 开局准备

- 显示关卡号、轨道缩略图、目标“让全部猫猫回窝”。
- 第 1～5 关隐藏广告标记。
- 道具库存为 0 时显示获得方式；不自动调起广告。
- 开始按钮是唯一主色按钮。

### P05 暂停

- 游戏画面加 55% 暖灰遮罩，但保持可识别。
- 面板依次为继续、重开、设置、返回主页。
- 重开和返回主页需要二次确认；继续不需要。

### P06 胜利

- 星星依次点亮，总时长不超过 1.2 秒且可点击跳过。
- 显示分数、最大连锁、小鱼干。
- 主按钮“下一关”；次按钮“再玩一次”。
- 翻倍与分享是视觉次级按钮，不能与下一关同权重。

### P07 失败/复活

- 标题“罐头仓库挤满啦”，不使用“Game Over”。
- 第 1～5 关显示“免费帮一次”；之后显示视频图标和“看视频继续”。
- 主次顺序：复活、重试、返回地图。
- 第 6 关起，失败后始终可再次主动选择“看视频继续”，不显示“本局复活次数用尽”；展示本次真实奖励，保留免费重开与返回。广告加载中禁止重复发起，结束/取消后恢复正确状态。
- 广告加载中按钮显示加载态；失败后恢复并显示原因。

### P08 图鉴

- 3 列 × 4 行卡片；未解锁使用剪影和解锁星数。
- 已解锁卡片可进入详情，详情展示插画、名字、品种和一句吐槽。
- 新卡片显示小红点，查看后消失。

### P09 外观

- 顶部实时预览发射猫窝和拖尾。
- 下方标签只分“猫窝”“拖尾”，不增加复杂分类。
- 卡片状态：未购买、可购买、已拥有、使用中。

### P10 设置

- 音乐、音效、震动三行切换。
- 隐私说明和返回主页为文字行。
- 所有设置点击立即生效并保存。

## 5. 动效时间

| 动效 | 时长 |
|---|---:|
| 按钮按下 | 80ms |
| 按钮回弹 | 140ms |
| 页面淡入 | 180ms |
| 弹窗弹入 | 220ms |
| 当前/下一只交换 | 160ms |
| 普通贴贴预备 | 120ms |
| 回窝飞行 | 420ms |
| 队伍回吸 | 220～360ms |
| 呼噜暴走蓄势 | 300ms |
| 暴走批量飞行 | 650ms |
| 星星点亮 | 每颗 240ms |

动效遵循“快进入、稍慢回弹”。连续游戏操作不得因装饰动画锁定超过规格时长。

## 7. 视觉完成定义

- 所有 P00～P11 页面均有 750 × 1334 标准稿。
- 100 关各有一张独立、可编辑的 750 × 1334 游戏画面；共享组件允许复用，但轨道、入口、老巢、猫链和关卡参数必须逐关明确。
- 三种目标设备宽高比下无核心内容遮挡。
- 组件状态齐全，无默认控件和临时图标。
- 五只猫在前 20 关 64px、后 80 关 56px 显示尺寸下仍可辨识；颜色之外仍保留花纹/轮廓区分。
- 字体授权或系统字体来源明确。
- Figma 层级可编辑、命名清楚、重复元素来自组件实例。
- Cocos 截图与 Figma 的关键尺寸、颜色和层级一致。
