## M0 规格冻结

- 当前只执行此里程碑；ImageGen、Figma、Cocos 保持暂停。
- 先确认祖玛基础循环、唯一入口、单向轨道、中央发射器、唯一老巢与胜负时序。
- 当前整改：废止旧 20×5 映射，完成前十关独立轨道与首撞实验，再验证完整灰盒并扩展其余 90 关；详见 [轨道整改记录](TRACK_REDESIGN_REVIEW.md)。几何 PASS 不代表本里程碑通过。
- 最新阶段顺序按 2026-09-07 所有者要求：先做完百关几何与难度编排，不继续完整游戏开发。后期采用紧凑多层尺寸；广告复活第六关起不限次数，详见 [难度与复活规格](DIFFICULTY_AND_REVIVE_SPEC.md)。
- 完成产品、交互视觉、技术、关卡、资产和测试规格。
- 给所有可调数值命名并确定默认值。
- 明确 MVP 非目标和平台能力降级行为。
- 验收：文档之间无冲突，所有功能都有实现归属和验收条件。

## M1 视觉概念

- 前置条件：项目所有者已确认玩法逻辑，100 关独立路线与内容已通过几何、差异性、实际首撞/开缝、完整模拟与人工灰盒验证。
- 使用 ImageGen 生成 100 关视觉母版、主界面/结算组合设计板、五猫角色设计板。
- 检查五猫辨识度、竖屏层级、按钮可读性、轨道清晰度。
- 选定唯一视觉方向并保存到 `art/concepts/`。
- 验收：概念图达到可重建质量，无明显 AI 残缺、乱码和风格冲突。

## M2 Figma 设计系统与核心界面

- 前置条件：对应 ImageGen 母版已通过逐关视觉 QA。
- 在共享文件指定页面最右侧建立独立 `喵喵回窝 / MVP` Section。
- 先检查 Code Connect、既有组件、变量、样式；不合适时创建本项目本地令牌与组件。
- 建立颜色、间距、圆角、字号、阴影令牌。
- 建立按钮、图标按钮、货币胶囊、关卡节点、猫咪徽章、进度条、弹窗、Toast 等组件和状态。
- 完成 P00～P11 核心页面。
- 每个页面单独截图检查，再检查总览。
- 验收：可编辑、组件化、无覆盖其他项目、无需付费 Figma 功能。

## M3 Cocos 工程与纯逻辑核心

- 前置条件：全部 Figma 页面与 100 关设计已由项目所有者验收。
- 创建 Cocos Creator 3.8.8 TypeScript 工程。
- 建立领域模型、事件总线、关卡加载和平台适配层。
- 实现路径采样、有序队列、插入、匹配、回吸、连锁与呼噜暴走。
- 为纯逻辑模块建立 Node 可运行的单元测试。
- 验收：至少 1000 次随机序列模拟无数组越界、重复猫、负距离和结算死锁。

## M4 第一关可玩垂直切片

- 实现第一关受控序列、五猫、完整输入、反馈、胜负和结算。
- 对接概念图与 Figma 导出的首批资源。
- 实现本地存档、设置和基础数据事件。
- 验收：从启动到第一关结算完整可玩，30 秒保底暴走生效。

## M5 全部内容系统

- 实现 100 关数据、两类障碍、三类道具。
- 实现关卡地图、星级、小鱼干、12 张图鉴与外观。
- 实现连续失败隐形辅助。
- 验收：新存档可顺序玩完 100 关；旧存档迁移不丢进度。

## M6 抖音平台能力

- 对接安全区、震动、生命周期、激励广告、录屏、分享、分析和云存档降级。
- 开发环境使用 Mock 适配器，真机使用 Douyin 适配器。
- 验收：能力成功、失败、取消、无填充、弱网均有可恢复路径。

## M7 QA 与发布候选

- 执行功能、回归、性能、视觉、多尺寸和异常测试。
- 检查主包大小、资源引用、日志、隐私与审核文案。
- 生成发布候选构建和已知问题清单。
- 验收：P0/P1 缺陷为 0；P2 仅允许有明确规避方案的非阻塞问题。
