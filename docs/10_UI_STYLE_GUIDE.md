## 1. 风格交付

- 候选图、最终提示词、修正记录与自检统一存放在 `art/concepts/ui03/`，与停用的 `v2_ui` 队列分开。

- 第一版的逗猫棒误画成星星魔法棒，修正目标为“短杆 + 弯曲绳 + 大羽毛”的猫玩具。保留第一版用于追溯，不覆盖旧图。

## 2. 可保持的视觉特征

猫是画面主角：大头、短身、收拢的小爪，面部大色块优先于毛发细节。材质采用短绒的柔软感和宽高光，避免逐根毛发、反光塑料或玻璃果冻。光源统一左上，阴影短而轻；游戏内猫耳、轮廓和尾部都要收在实际显示尺寸内。

按钮与面板比猫更平：薄边、柔和高光、宽阔文字区。首页可有一处主猫装饰，弹窗可有一处星星/小猫贴花；贴花独立于底板，不进入拉伸区。游戏背景以大面积暖色底为主，少量低对比装饰先按面积不超过 8% 试排，轨道附近留空，不直接照搬概念图中的落地阴影。

同一屏只让主要动作使用暖橘。薄荷色用于完成/呼噜的辅助反馈，粉色用于少量装饰；警戒只在老巢与末段呈现柔和珊瑚色和形状/文案，不用满屏红闪。颜色不作为猫品种、禁用或警戒的唯一识别方式。

## 3. 五猫识别规范

| 品种 | 必须保留的大特征 | 缩小时先舍弃 | 防混淆 |
|---|---|---|---|
| 橘猫 | 橘底、额头三条宽条纹、奶油口鼻 | 身体细条纹、胡须 | 与三花区分：整体橘色且对称 |
| 布偶 | 奶油底、可可耳/面罩、宽白色倒 V、蓝眼 | 碎毛、细渐变 | 与蓝猫区分：白 V 与浅身体 |
| 蓝猫 | 整体蓝灰、圆宽脸颊、琥珀眼 | 胸部细纹理 | 无额头条纹、无白 V |
| 三花 | 奶油底、一橘一深色的大脸斑、耳色不对称 | 零碎小斑 | 大块不对称，不能变第二只橘猫 |
| 玄猫 | 深炭紫、尖耳、浅黄绿眼、可辨口鼻 | 黑底细毛和细胡须 | 不能只剩一团黑；保留脸部明暗分区 |

五猫共享近正面视角和统一形体比例，不把每个品种做成截然不同的玩偶尺寸。新基础品种、彩虹普通猫和炸弹猫不在范围内；彩虹猫只在道具组表达。

缩小预检按 64/56/48 CSS 像素框等比显示板上的五个样本，并额外查看灰阶。它只回答“概念大特征是否仍可区分”：概念板含底色、非透明、各猫实际包围盒不同，不能将该结果当作真实猫径、透明边缘、轨道动态辨识或真机通过。正式检查需要 UI-04 的独立源与 UI-03G/05 的真实坐标。

## 4. 色板与对比度

| 语义 | 色值 | 使用范围 |
|---|---|---|
| 背景 | `#FFF5E6` | 局内/首页暖底 |
| 面板 | `#FFFBF4` | 弹窗、主要卡面 |
| 安静次表面 | `#F2E6D5` | 次级分组 |
| 主文字 | `#4A332B` | 标题、按钮、重要数字和语义图标 |
| 次文字 | `#785E50` | 说明；不通过降低整个节点透明度获得 |
| 主按钮 / 按下 | `#FFC078` / `#E8A456` | 暖橘底，搭配深棕文字 |
| 禁用底 / 字 | `#E8DFD4` / `#6F5C4E` | 仍可读，另用文案/加载状态解释 |
| 薄荷浅底 | `#A9D8C0` | 轻量成功提示；不替代细进度填充 |
| 呼噜填充 / 槽 | `#548B70` / `#E8E1D2` | 16px 细槽，文字放在外侧 |
| 装饰粉 | `#F4C6CC` | 小面积爱心/爪印 |
| 警戒浅底 / 字 | `#F4B8A7` / `#7A3D32` | 局部警戒，文字深色 |
| 装饰边 | `#D9C4AA` | 非唯一语义边缘；交互识别依靠图标/文字/填充 |

项目预检目标：普通文字配对至少 4.5:1，细进度填充与槽底至少 3:1；禁用文字也沿用 4.5:1 的项目要求。计算采用线性化 sRGB 相对亮度，按未四舍五入值判断；这是候选色对检查，不声称游戏达到整套无障碍标准。[W3C 对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

已算得：主文字/背景 10.81:1，次文字/面板 5.79:1，主按钮 7.26:1，按下按钮 5.49:1，禁用 4.80:1，警戒文案 4.83:1，呼噜填充/槽 3.04:1。十组配对全部达到各自草案目标。浅橘配白字只有约 1.61:1，不采用；警戒文字初稿未达目标，已加深修正。实际渐变、阴影、压缩和缩放后仍需重测。

## 5. 字体候选与排版

| 候选 | 建议用途 | 本轮结论 |
|---|---|---|
| Noto Sans CJK SC | 推荐先用于正文、HUD、按钮与数字；500/700 两档 | 字形清楚，适合先建立稳定排版；具体字体文件尚未导入或实测 |
| LXGW WenKai / 霞鹜文楷 | 可在首页大标题、图鉴短句做对比候选 | 手写感更温和；不默认用于 24/28px HUD 或动态计数，避免笔画缩小失真 |

Noto 的官方仓库提供不同地区/格式资源，生产时选择简体中文所需字体并核对引擎支持，避免把整个多地区集合塞入首包。[Noto 官方下载说明](https://github.com/notofonts/noto-cjk/blob/main/Sans/README.md)

两者官方许可证均为 SIL OFL 1.1。导入时保存实际版本、文件哈希、版权与许可证；子集或改名需对照所下载版本的保留名称条款。霞鹜文楷当前附加说明对保留名称的部分许可有具体条件，不能直接推定所有游戏内子集化都适用。本轮只确认候选来源，没有下载/安装/子集化字体，也没有声称缺字检查通过。[Noto 许可证](https://github.com/notofonts/noto-cjk/blob/main/Sans/LICENSE)、[霞鹜文楷许可证](https://github.com/lxgw/LxgwWenKai/blob/main/OFL.txt)

750×1334 基准的试排：标题 48/行高62，页面标题36/48，按钮34/44，正文28/38，辅助24/32，数字28/38；字距0。按钮图标36、与文字间距12，图标与文字整体居中。Label 不烘焙到图片，不用自动缩字掩盖长文案溢出。空间不足先调整文案或布局；奖励、免费、视频等关键信息不得省略。

必测文本：`喵喵回窝`、`第 100 关`、`继续第 100 关`、`免费重新开始`、`视频 · 看完继续`、`暂时没有视频`、`正在帮猫猫腾位置…`、`额外 +999 小鱼干`、`逗猫棒 ×99`、`0 / 100`。最终字体选择需包含上述字符、标点和动态数字，并检查大小写乘号/加号/省略号。

## 6. 组件尺寸与状态

基础间距8/16/24/32/48/64；按钮圆角32、面板40、小卡16；UI装饰边2、选中边4。默认阴影参考 x0/y4/blur8/14% 深棕，按下 y1；只描述外观，Cocos 可通过合适底图实现，不引入实时模糊的硬要求。

主按钮先用480×96，短次按钮可用230×96；水平留白32。图标可见64，触区88×88；按压只改变视觉，不缩小/移动热区。弹窗宽606、内边32，实际高度按09内容与安全区调整。

| 组件/状态 | 视觉与行为约束 |
|---|---|
| 主按钮 Normal | 暖橘底、深棕文字、短阴影；同屏唯一最强操作 |
| Pressed | 颜色稍深、视觉高度97%、阴影变短；80ms压下、140ms恢复；禁用不触发 |
| Disabled | 禁用底与深灰棕字、无主阴影；不做整组低透明；保持真实原因 |
| Loading | 文案/加载指示占固定区域，防重复发起；不挤动按钮，也不顺带禁用免费退出 |
| Rewarded | 视频标记与奖励写清；取消/失败回可重试状态；复活恢复期间免费重开/地图仍可选 |
| 道具 Available/Empty | 图标 + 短名/数量；空库存保留说明入口，不自动调广告 |
| 道具 Selected/Busy | Selected 以边框和“取消”表达；Busy 保留品种/数量但禁用命令；取消不扣库存 |
| LevelNode | 当前用暖橘；完成显示星级；锁定显示锁与条件；不得只换灰色 |
| Purr | 细槽，不在填充上压小字；满/暴走以外置符号/短提示表达，数值和时机读核心 |
| Popup | Pause/Win/Revive 共底板，内容和主操作不同；遮罩55%暖棕、输入只给顶层 |
| Toggle/Toast | 开关除颜色还改变滑块位置/开关语义；Toast 不挡当前猫或道具，不拦手势 |

UI 动效沿用现行试排时长：页面180ms、弹窗220ms、交换视觉160ms、星星每颗240ms；庆祝可跳过。减少动效时以约80ms直接过渡，不摇晃/弹跳。这里只约束表现层，不改核心回吸、出猫、碰撞或暴走算法。

## 7. 独立资产与九宫格实验

按钮源模板可先试192×128、左右 inset48、上下40；面板模板256×256、四边56。它们是**待验证的制作模板**，不是从风格板量出的切线；正式值由独立源的角、边、阴影实际边界确定。按钮需验证230/480/520宽度、88/96高度；上下固定区域之和须小于最小按钮高度，留出拉伸区。面板检查最短暂停内容与最长复活文案。

阴影若不能随九宫格正确拉伸，可独立作为下层或重做底板；不靠拉长阴影补视觉。星星、面板小猫、视频徽记、锁、关卡号和按钮文字全部分离。进度底/填充分别管理；轨道从 catalog 同源几何生成，不使用板上任意线条替代。

进入首批独立资产前确认：五猫小尺寸方向、按钮材质、面板边厚、字体候选；随后按 [09](09_UI_STRUCTURE_AND_STATES.md) 的 A01～A10 分批做。UI-03 不提前输出一整套生产图或空 Prefab。
