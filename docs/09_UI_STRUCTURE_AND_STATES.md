## 2. 页面清单与返回契约

页面 ID 表示功能，不要求十二个独立场景或十二张满屏 Prefab。Settings、Prepare、Dialog 和 Toast 可在一个场景中组合。

| ID | 形态与必需内容 | 进入 | 主操作 | 返回/关闭 |
|---|---|---|---|---|
| P00 启动 | 加载/合规、进度或真实阶段、重试 | 冷/热启动 | 资源可用后进入 P01 | 加载失败留本页；离线仅在必要本地资源齐全时进入 |
| P01 首页 | 游戏名、主猫、小鱼干、主按钮、三个次入口、小设置 | P00、退出确认、地图返回 | 新用户“开始回窝”，回流“继续第 N 关” | 根页面，无自造系统退出按钮 |
| P02 地图 | 十章脚印节点、100 关、历史星级、当前关 | P01、P07、末关结算 | 点已解锁节点进入 P03 | P01；记住滚动位置，首次定位当前关 |
| P03 准备 | 轻量准备面板、关卡/目标/源几何缩略、道具信息 | 首页继续、地图选关 | “开始回窝”进入 P04 | 回到调用它的首页/地图，保留位置 |
| P04 游戏 | HUD、入口/轨道/猫链/中央窝/下一只/老巢、三道具 | P03、重开、复活、连玩下一关 | 瞄准发射/交换/道具 | 只能经 P05/P07/结算导航离开 |
| P05 暂停 | 继续、重开、设置、返回首页 | 暂停按钮、局内后台恢复 | “继续回窝” | 关闭等于继续；重开/退出先确认 |
| P06 胜利 | 星级、分数、最大连锁、小鱼干、下一关、次级奖励/分享 | 有效 Won 快照与结算结果 | 第 1～99 关“下一关”；第 100 关“返回地图” | 重玩当前关、返回首页；不退回已结束会话 |
| P07 失败/复活 | 失败原因、真实复活效果、复活/重开/地图 | 有效 Lost 快照 | 视资格显示免费/视频复活；免费已用时重开 | 返回地图；不使用含糊 X 回到已失败的游戏 |
| P08 图鉴 | 12 卡、锁定/已解锁/新卡、详情短句 | P01，解锁后轻提示 | 已解锁卡打开详情 | 详情回列表；列表回 P01，保留滚动 |
| P09 外观 | 猫窝/拖尾两类、预览、鱼干价格、购买/应用 | P01 | 对应状态的购买/使用 | P01；不引入内购或成长数值 |
| P10 设置 | 音乐/音效/震动、隐私、返回 | P01/P05 | 切换立即保存 | 返回调用者；从暂停进入时回 P05，游戏保持暂停 |
| P11 通用提示 | Toast、加载、离线、无广告、奖励/错误 | 所有页面 | 必要时重试/取消 | 返回所属页面，不另起导航栈 |

图鉴解锁沿用第 3 关通关后轻提示。解锁前首页图鉴可显示锁定并说明条件；不弹出强制教学。卡片自身仍按已确认星数解锁；界面入口与单卡解锁条件分开表达。

### 建议导航

```text
启动 → 首页 → 准备 → 游戏 → 胜利 → 下一关
        ├→ 地图 → 准备       ├→ 重玩 / 首页
        ├→ 图鉴 → 详情       └→ 第100关：地图
        ├→ 外观
        └→ 设置

游戏 → 暂停 → 继续 / 重开确认 / 设置 / 退出确认
游戏 → 失败 → 免费或视频复活 → 原局
              ├→ 免费重开 → 新局
              └→ 地图
```

连玩建议：P06 的“下一关”完成必要加载后直接进入下一关，避免每关重复点击准备面板；首页/地图主动选关仍保留 P03。该连玩优化为拟议交互，待灰盒验证，不删除开局准备/补给能力，不在本轮改代码。

重开保持当前关卡 ID，创建新局；复活恢复对应失败快照，保留当前局 ID。回流“继续第 N 关”指进入当前关卡，不承诺恢复应用被杀前的半局进度；持久化半局恢复未获产品授权。

### 基准坐标与占位尺寸

坐标以 750×1334 左上为原点，x 向右、y 向下；下表均为**试排参数**。运行时把设备安全区/胶囊矩形换算到布局坐标后再检查，不能直接混用屏幕像素、DPR 和 Cocos 坐标。

| 对象 | 基准位置/范围 | 布局约束 |
|---|---|---|
| 顶部安全带 | y=0..88 | 仅背景；不足以证明所有设备安全 |
| 暂停热区 | x=32..120，y=88..176 | 88×88，放左侧，降低与右侧胶囊冲突的机会 |
| 关卡行 | x=144..304，y=92..132 | 36 号起排；兼容“第 100 关” |

| 呼噜槽 | x=144..610，y=150..166 | 独立槽底和填充，右侧 x=626..718 标“呼噜”；不增加点击热区 |

目标进度不编造“已救 N / 总生成数”百分比：玩家发射也会增加场上猫，分母与完成定义需要真实数据契约。此版先用目标文本和入口状态表达进展；如果后续采用数字，必须由核心提供定义明确的进度字段。呼噜条只读取核心快照，不重算 Q003 中未统一的公式。

### 几何核对证据与边界

本轮只读调用 `makePath`、`parameterize`、`resample`、`at`，以约 2px 路程步长检查全部 100 关；包围范围取 `max(轨宽/2, 猫半径)`，设施按现有工具的 80px 洞口宽、40px 深示意矩形计算。它们是采样结果与占位设施估计，不是正式资源或动态碰撞验收。

| 样本 | 轨道/猫基础包络 y 范围 | 用途 |
|---|---|---|
| L001 | 276..1074 | 首关留白、五猫和首次引导 |
| L020 | 221..1104 | 64px 档末端、近中央轨道 |
| L021 | 253.99..1021.22 | 56px 档起点 |
| L100 | 303.74..1112.73 | 多层密集与末关结算 |
| L022 | 192..1158 | 贴近上下边界，补充首轮适配样本 |
| L024 | 基础包络 192..1158；设施可至 188..1162 | 检查旧 HUD/道具区的重叠问题 |

因此把 HUD 收在 y=176 以内，道具上边下移至 y=1172，按目前设施示意分别留下约 12px/10px 间隔。**这只是基准画布的占位余量**：正式设施高光、猫耳、描边、按压动画、热区和安全区变化都可能吃掉它，灰盒必须再次核验，不能直接标“百关适配通过”。

固定下一只猫中心 `(423,717)`、预览半径 28 的首次估算，在个别紧凑关仅余约 5px，未含边框。有限右下候选加入 4px 预览边框后，最差 L087 仍只余约 6.60px，小于建议 8px 的资源间隔；列为 **UI-R01 待灰盒解决**。L100 候选 `(394.67,748.41)` 的占位间隔约 14.49px，仅作为试样输入。

先调整下一只预览的装饰留边/右下候选位置，保持品种可辨和当前猫不重叠；如果仍不够，提交局部组件布局方案，不改几何、不擅自缩小猫、不移动中央发射器。UI-03G 加入 L022/L024/L087，不能只验证宽松首关。

### 输入与反馈

- 手势从 UI 热区开始，整次手势归该 UI；松手不穿透为射击。从玩法开始的瞄准若被弹窗、后台或道具态中断，取消本次发射。
- 拖动超过现行 16px 阈值按瞄准处理；中央点击交换；回中央 48px 内松开取消发射。预览气泡先只展示，交换操作仍在中央窝，避免新增不明热区。
- 暂停/设置/道具说明/确认期间玩法不接受输入；UI 只发命令，能否执行由核心状态决定。
- 逗猫棒和猫薄荷进入选目标态，重复点击当前道具或底栏“取消”退出；取消不扣库存，成功执行才扣一次。点到空轨道提示重新选目标，不误发射。
- 彩虹猫替换当前发射猫，下一只不变；仅核心接受替换后扣一次。飞行/解析/复活恢复期间按核心能力禁用，不缓存一次意外使用。
- 三道具“数量为零”点击只说明当前可用获取方式，不自动调广告，不新增局内广告位。局内只提供信息和返回游戏，开局补给仍属 P03。
- 危险提示只沿末段/老巢；呼噜暴走的装饰不能长时间遮挡发射猫、下一只和猫链。阈值由核心事件输入，Q003 未决数值不写进 UI。

### P06 胜利

```text
猫猫到家啦！（候选标题）
       星级 / 庆祝占位
分数    最大连锁    本次小鱼干

        [下一关]
      [再玩一次] [首页]
   [视频翻倍 +N]   [分享高光]
```

奖励先区分基础、首次和翻倍增量，视频按钮显示真实“额外 +N 小鱼干”，不能暗示首次奖励也翻倍。第 1～5 关默认不主动展示奖励广告入口；广告相关前五关例外仍查 GDD，不由 UI 自行加入口。分享按能力显示视频或普通分享，取消不发奖，不影响已发基础奖励。

星星动画可跳过；下一关不等完整庆祝动画。基础结算未落账时显示短加载并阻止重复领奖，失败可重试；不能先改余额再希望存档成功。奖励事务处理中切页的细节由技术任务保障；不让新局等待一个无法结束的旧回调。

## 5. 失败与广告状态矩阵

本表是 UI 契约；广告调用、奖励与会话恢复属于 TECH-04。广告由玩家主动点击，试样只模拟状态，不能把重开当复活。

| 状态 ID | 条件/显示 | 可操作 | 成功或异常后的落点 |
|---|---|---|---|
| R-FREE | 第1～5关，当前局免费未用 | 免费帮一次 / 免费重开 / 地图 | 有效恢复后 P04；失败留原快照，免费资格不提前消耗 |
| R-FREE-USED | 第1～5关，当前局免费已用 | 免费重开（主）/ 地图 | 重开新局；不调用广告 |
| R-READY | 第6关起，原失败快照有效 | 视频继续 / 免费重开 / 地图 | 点视频创建本次尝试，进入 R-LOADING |
| R-LOADING | 本次广告正在准备 | 视频按钮加载防重入；免费重开/地图仍可选择 | 若离开先使本次尝试失效；晚到回调不得播放广告或改新局 |
| R-PLAYING | 平台广告覆盖游戏 | 使用平台提供的广告关闭/取消能力 | 等有效结束结果，未完成/中断回原失败快照；不擅自覆盖平台控件 |
| R-CANCEL | 未完整观看/用户取消 | 提示“视频未看完，未获得帮助”；恢复 R-READY 操作 | 不发奖、不重置关卡、不减少资格 |
| R-UNAVAILABLE | 无填充、网络或播放失败 | 原因提示；免费重开/地图立即可用 | 广告重试按能力/既有冷却恢复，不自动循环弹广告 |
| R-RESTORE | 本次有效完成，恢复事务执行中 | 显示“正在帮猫猫腾位置”；阻止重复恢复；免费重开/地图仍可选 | 仍在原局时成功回 P04；已离开则不跳转或改新局；异常保留原局凭证可重试恢复，不要求再看一次已完成广告 |
| R-REPEAT | 同局再次失败且第6关起 | 与 R-READY 相同，不因复活次数禁用 | 新失败快照、新广告尝试；每次独立有效完成可再次复活 |
| R-STALE | 重复/迟到/跨局回调 | 不覆盖当前界面，不重复奖励 | 同次结果幂等；其他有效的新尝试仍可生效 |

“免费重开/退出始终可选”覆盖本项目失败页，包括加载和恢复中。平台广告覆盖期间不能声称自有按钮仍能盖在广告上；关闭/结束后立即回可操作失败页。恢复时选择离开仍需使视图与旧局解绑，旧局奖励凭证不转移到新局；事务须有错误恢复路径，不保留无限转圈状态。

保存和核对身份至少包括当前局、失败快照、本次广告尝试和本次奖励事务。重开/返回先解除界面与旧局绑定；同局新失败不能被前一次广告的晚到消息恢复。

### 首次操作与道具说明

引导作为 P04 的局部提示层，不增加第十三个主页面。建议一次只解释一个动作：首次瞄准显示“松手，把猫猫送去贴贴”；交换提示指向中央窝并显示“点一下猫窝，交换猫猫”；呼噜触发时使用短提示，不盖住猫链。提示锚定实际目标位置，不能根据首关截图硬编码猫的位置。

引导完成以真实操作事件为依据，后台/弹窗中断时隐藏提示并取消未完成手势，回到游戏后按当前状态恢复；不因点击提示的透明区域额外发射。暂停、重开和退出入口保持可用；重玩不强制重复已完成步骤。道具说明使用通用面板，关闭回调用者，说明本身不扣库存。具体触发时机与完成记录在引擎任务中绑定，不能用提示层改首关受控序列或呼噜数值。
