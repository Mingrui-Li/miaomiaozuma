## 一份资产直接复用

D017（2026-09-11）：所有者要求后续新增图片使用GPT Image 2.5。官方模型为 [Sunburst](https://developers.openai.com/api/docs/models/gpt-image-2.5-sunburst) 和 [Flare](https://developers.openai.com/api/docs/models/gpt-image-2.5-flare)；精确修改/风格保持任务建议Sunburst。当前内置生图工具只有prompt/参考图片参数，无法指定或核实实际型号，模型通道仍待满足。后续生图前核验支持情况；不改写UI-04模型未知的历史记录，不因型号要求自动调用付费API。

新路线见 [08](08_UI_DEVELOPMENT_ROADMAP.md)，D012 已承接为后续规划依据。交付原则：背景、轨道、猫、设施、按钮底板、图标、文字必须能分别控制。正式 UI 文字由引擎 Label/获准字体渲染，不把整屏生图烘焙为按钮和 HUD；可批准的标题 Logo 是例外，仍需独立资产。

推荐将 image-2 风格板标记为概念参考，独立制作生产素材；同一份导出资产直接导入 Cocos，Figma 只展示同源资产或引擎截图。不得经 Figma 截图/重复有损导出再进入引擎。先做 UI-05 需要的一批，经实际尺寸与交互检查后再扩展。

未来每项资产记录：稳定 ID、用途、源文件、生成工具/实际可确认模型或作者、授权来源、尺寸、透明度、锚点、导出路径、引用位置、状态（候选/通过/返工/停用）。无法确认模型时如实写未知；ChatGPT Plus 不能被当作独立 API 付费授权。

UI-04 清单建议再记录显示尺寸/导出倍率、内容边界、九宫格 inset、压缩参数、哈希、Bundle 和实际 Prefab 引用；清单和批准截图一起版本化。目录按需创建，不为规划新增空资源或 `.meta`。

## 图片与图标

- 透明猫咪/图标优先保留无损 PNG 源；不透明背景可评估 JPEG 等导入方案。具体生产压缩格式以目标构建/真机支持验证，不凭本文自动启用。
- 按实际显示尺寸制作，避免巨大整屏素材缩成小图标；普通猫源图可从 256×256 起试，实际检查 64/56px，48px 额外压力测试。
- 统一光向、描边、透明留边与锚点，序列帧画布一致，不随表情改变逻辑碰撞半径。
- 检查黑白底透明边缘、脏像素、错误耳朵/爪子、轮廓缺损和水印；禁止拉伸修尺寸、截屏拼补冒充源文件。
- 命名使用小写蛇形英文，如 `cat_orange_idle_01.png`、`ui_button_primary.png`。示例只是命名约定，不表示文件已存在。

## 九宫格与轨道

- 按钮底板、弹窗底板、进度槽适合评估 Cocos SLICED 九宫格：四角保持，边缘单轴延展，中心填充。
- 每张记录左右上下 inset；拉伸区域不能含猫脸、文字或固定形状图标。验证最小/最大宽度，不凭图片边缘猜切线。
- 曲线轨道不是随意拉伸的九宫格：几何必须由百关源生成，纹理/边缘装饰服从路径；具体绘制方式待引擎试样决定。
- 入口和老巢分别制作单洞口，锚点标在洞口中心，朝向服从切线，不能用一张整图画死多个关卡位置。

## 字体

- UI-03 已核验 Noto Sans CJK SC、霞鹜文楷官方来源和 OFL 1.1 许可证，作为候选；未选定、下载或导入具体字体。实际交付仍需许可证/版本/哈希/字符覆盖，不能据候选来源宣称生产字体齐全。
- 标题/正文/数字按统一样式管理；按钮文本包含图标时整体居中，数字宽度变化不挤动其他元素。
- 系统字体仅可作为标明的原型回退，跨设备不能据此宣称字形一致。
- 字体子集化需授权允许，并先列出实际字符；检查动态关卡号、奖励数字、异常文案和缺字回退。不要把大中文字库无检查塞进首包。

## 图集、压缩与分包

- 主包目标小于 4MB 是项目预算，不是本轮核验过的平台法定上限。发布前另行核对平台规则和实际构建体积。
- 通用小图按共同加载/释放时机合图集；猫/局内反馈、通用 UI、图鉴分开评估。留透明 padding/extrude 防串色，具体尺寸按导出与真机结果定。
- 大背景不塞入常驻小图图集；不为追求少一次 draw call 让整个百关资源常驻。
- 启动、首页、首关、五猫最低必要状态与通用 UI 优先首包；章节背景、图鉴大图、非默认外观按需 Bundle。当前尚未配置完成，不能把规划当成现状。
- `resources` 中的资源应审查引用与加载方式，未来分包按需迁移；本轮不移动。重复文件/跨 Bundle 引用可能导致重复打包，发布构建时实测。
- 先裁切与去冗余，再测试质量/压缩格式；超 512KB 单图列入复查。文件体积、解码后纹理内存和加载时间分别测量。
- 不对源图做不可逆覆盖；压缩输出保留来源和参数。加载失败有重试，离开页面释放不再引用的大图。

## 验收清单

来源与授权可追踪；五猫缩小可辨；透明边缘干净；九宫格不变形；字体无缺字且位置正确；导入 `.meta` 和引用完整；多尺寸清晰；无重复打包；实机内存/帧率/首包有证据。旧素材只能逐项复审复用，不以“已经在仓库”直接批准。
