# 《喵喵回窝》资产规格

> 2026-09-08 本轮更新：本文件下方旧“当前状态”、逐关等待及 ImageGen → Figma → Cocos 强制流程仅作历史记录，已被 [D008](05_DECISION_LOG.md) 取代；当前仅建立项目记忆，新 UI 流程待确认，禁止自动续跑旧生产任务。未被替代的玩法/质量要求保留；具体状态、几何来源与残留冲突见 [06](06_CURRENT_STATE.md)，新 UI 方向见 [01](01_UI_DIRECTION.md)。

## 1. 目录约定

```text
art/
  concepts/          ImageGen 概念图与提示词记录
  source/            经确认的高分辨率源图
  exports/           从 Figma/源文件导出的生产资源
  qa/                对照截图和联系表
assets/
  game/art/          Cocos 可导入图片
  game/audio/        音频
  game/fonts/        已确认授权的字体
```

不得把仅存在于外部临时地址的资源写入代码。所有生产资产必须保存在仓库中并有稳定文件名。

## 2. ImageGen 首批概念图

### C01 第一关完整画面

- 竖屏 9:16，高保真游戏 UI 概念图。
- 同时出现五种可辨识猫咪、唯一迷路入口、连续开放轨道、正中央 360° 猫窝发射器、单入口罐头老巢、呼噜槽、暂停按钮、下一只猫。
- 入口必须只接 `s=0`，轨道脚印必须沿唯一方向指向老巢，老巢必须只接 `s=L`；不得出现闭环、C 形断头、双入口或底部发射器。
- 表现一次即将触发的贴贴，突出轨道清晰度和单手操作。
- 图中文字只保留可控的少量中文；正式文字在 Figma 重建。

### C02 核心页面设计板

- 同一画风展示主界面、胜利结算、失败复活三张竖屏缩略图。
- 主界面突出标题、五猫和继续按钮。
- 胜利页突出三颗星、猫咪回窝和下一关。
- 失败页保持可爱、不恐怖。

### C03 五猫角色板

- 橘猫、布偶、蓝猫、三花、玄猫并排。
- 每只包含正常、开心、紧张三个表情参考。
- 统一 3/4 正面圆团造型，粗轮廓，缩小仍可分辨。
- 不含写实毛发，不含背景文字和水印。

每张概念图的最终提示词保存为同名 `.prompt.md`。

## 3. 猫咪生产资产

每种基础猫需要：

| 资源 | 帧数建议 | 用途 |
|---|---:|---|
| idle | 4 | 队列呼吸、眨眼 |
| squeeze | 3 | 插入挤压 |
| cuddle | 5 | 贴贴预备 |
| fly_home | 6 | 回窝飞行 |
| nervous | 4 | 靠近终点 |
| celebrate | 6 | 结算庆祝 |

生产建议：单帧源图 256 × 256，实际游戏显示约 64px；图集保留 4px 透明边距，使用预乘透明兼容设置。

必须存在的特殊猫/状态：

- 彩虹猫
- 纸箱猫：HP2、HP1、打开
- 灰扑扑猫：遮蔽、揭示过渡
- 五猫剪影

## 4. 场景与 UI 资产

- 背景：庭院天空、远山/屋顶、草地，分层以支持轻微视差。
- 轨道：普通、危险末段、转弯装饰；轨道本体尽量用九宫或矢量方式减少包体。
- 终点：罐头仓库正常、警戒、挤满。
- 发射器：默认猫窝、按下、交换、空状态。
- 纸箱：空、装猫、打开。
- 粒子：爱心、猫爪、星星、呼噜波纹、小鱼干。
- 图标：暂停、设置、返回、关闭、视频、分享、音乐、音效、震动、锁。
- 道具：逗猫棒、猫薄荷、彩虹猫。
- 图鉴：12 张主插画或统一卡面中的角色姿势。

## 5. 音频清单

| ID | 内容 | 时长/要求 |
|---|---|---|
| BGM_HOME | 主界面循环 | 45～75 秒，无人声 |
| BGM_GAME | 局内循环 | 60～90 秒，节奏轻快 |
| SFX_SHOOT | 发射 | <0.4 秒 |
| SFX_INSERT | 插入挤压 | <0.25 秒 |
| SFX_MATCH_1..4 | 连锁分级 | 音高逐级上升 |
| SFX_PURR_READY | 呼噜槽满 | <0.8 秒 |
| SFX_PURR_FRENZY | 暴走 | 1.5～2.5 秒 |
| SFX_HOME_FLY | 回窝飞行 | <0.8 秒 |
| SFX_WIN | 胜利 | 2～3 秒 |
| SFX_FAIL | 失败 | 温和，1～2 秒 |
| SFX_BUTTON | 通用按钮 | <0.2 秒 |
| SFX_REWARD | 奖励到账 | <0.8 秒 |

喵叫使用短促拟声音效，不使用可能被误解为受伤或惊恐的叫声。

## 6. 资源预算

- 主包只包含启动页、主界面、第一关、五种基础猫最小动画、通用 UI 和必要音频。
- 主包目标小于 4MB。
- 其余关卡背景、图鉴大图和外观进入分包。
- 单张非图集 PNG 超过 512KB 时必须检查裁切、格式和压缩。
- 同类小图合并图集；大背景按需加载并及时释放。

## 7. 资产验收

- 透明边缘无黑边、白边或脏像素。
- 五种猫在 64px、48px 两种尺寸下可辨识。
- 画风、光向、描边粗细和阴影方向一致。
- 不包含水印、乱码、错误肢体、额外耳朵或不自然眼睛。
- 文件命名使用小写蛇形英文，不使用空格和中文路径。
- 所有第三方字体、音乐、音效和素材有可追踪授权来源。
