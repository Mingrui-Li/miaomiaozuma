## 实现与范围

新场景 `assets/ui-flow/ui-flow.scene`，UUID `5f337c54-11dc-4bf4-aa56-1ea4b905e356`。FlowView负责页面组合和导航，FlowModel是无Cocos依赖的内存演示适配器，FlowBase保留七关布局/触控绘制能力。复用UI-04十二张PNG、UI-05四个Prefab；已验收的UI-05场景、字体、脚本、meta均不改。

这是 **UI流程预览**。没有绑定旧GameSession、SaveService、平台广告或支付；余额、星数、库存和结算是明确标注的演示样本，刷新后重置。不得据此宣称真实购买、奖励、音效、震动、存档或广告已经实现。

## 操作与状态选择

默认演示档：当前24关、180鱼干、24星。开始可进入24关；底部工具栏属于预览工具，不是正式游戏入口。

- “状态”中选择正常、网络失败、模拟取消后，后续加载/保存/奖励请求按所选结果返回。
- “首关引导”切首关，“终章与全图鉴”打开终章与全部卡片样本，“发射忙碌”切换局内禁用。
- “胜利”“复活”展示对应状态；“启动”重新演示启动流程。“安全区”模拟顶部胶囊与底部留白。
- 设置保存和解锁外观均只修改FlowModel的内存。所有请求带唯一ID，离开/取消使旧ID失效。浏览器状态记录在只读 `window.__UI_FLOW__`，实际操作通过Canvas触控。

## 文字与布局

扩展字体 `assets/ui-flow/mmhw_ui_flow.ttf`，Noto Sans SC 2.004的500字重子集，改名MMHW UI Flow；原始OFL字体和版权来源沿用UI-05。新子集、cmap、版本和哈希见 `design/ui/ui06/font.json`，旧UI-05字体不覆盖。

复查发现动态Label在初始化时会重算尺寸，引起短行过度缩小；已在配置完成后重新设置UITransform尺寸，并按文本宽度限制字号。长文案不直接依赖未知收缩结果。提示移到底部状态行，导航时清除，避免旧提示压住返回按钮。

全部产品热区仍以44 CSS px为最小值，多尺寸保持一个场景整体变换；页卡使用分页避免短屏塞满大量入口。轨道不为适应新页面改形。
