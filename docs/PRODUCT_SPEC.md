> 2026-09-08 本轮更新：本文件下方旧“当前状态”、逐关等待及 ImageGen → Figma → Cocos 强制流程仅作历史记录，已被 [D008](05_DECISION_LOG.md) 取代；当前仅建立项目记忆，新 UI 流程待确认，禁止自动续跑旧生产任务。未被替代的玩法/质量要求保留；具体状态、几何来源与残留冲突见 [06](06_CURRENT_STATE.md)，新 UI 方向见 [01](01_UI_DIRECTION.md)。

> 规格版本：1.0.0  
> 基线日期：2026-09-04  
> 适用版本：抖音小游戏首发版（100 关）
> 当前状态：2026-09-08 已授权基于当前百关几何制作全套 ImageGen UI；动态玩法待验证，Figma 与 Cocos 本轮不启动。

## 1. 目标与非目标

### 1.1 产品目标

- 新用户在进入可交互画面后 10 秒内完成第一次发射。
- 新用户第一局看到五种猫、至少三次贴贴和一次呼噜暴走。
- 单局时长控制在 60～120 秒，前三关连续体验不被广告打断。
- 用极少系统形成“关卡挑战—获得小鱼干—解锁图鉴/外观—继续挑战”的闭环。
- 所有关键高光可被自动录屏捕获并在结算页分享。

### 1.2 MVP 非目标

不包含实时联网玩法、账号注册页、聊天、公会、排行榜、体力、抽卡、猫咪养成、公寓装修、支付、用户图片上传、实时 AI 生成和运营后台。

## 2. 运行与显示基线

- 逻辑设计分辨率：750 × 1334，竖屏。
- 安全内容区：顶部至少 88px、底部至少 64px；运行时以平台安全区为准动态修正。
- 目标帧率：60 FPS；低端设备最低可接受 50 FPS，不能持续低于 45 FPS。
- 首次可交互目标：常规网络下 5 秒内；加载时必须显示进度或阶段提示。
- 单次触控：同一时刻仅处理一个主瞄准手势，忽略额外触点。

### 3.2 首次用户流程

`启动 → 合规展示 → 主界面 → 直接进入第1关准备 → 第1关 → 胜利结算 → 第2关`

- 第一次进入时，“继续游戏”默认进入第 1 关。
- 第 1 关准备页不展示道具和广告，只展示“五猫迎宾”和开始按钮。
- 第 1～3 关胜利结算的主按钮始终是“下一关”。
- 图鉴在第 3 关通关后以一次轻提示解锁，不弹出强制教学。

### 3.3 回流用户流程

`启动 → 主界面 → 继续当前未完成关卡`

- 主界面显示最近解锁猫的形象。
- “继续游戏”显示当前关卡号。
- 关卡地图、图鉴、设置是次级入口，不得抢过主按钮视觉权重。

## 4. 局内状态机

| 状态 | 可进入自 | 可转向 | 玩家输入 |
|---|---|---|---|
| Loading | 页面创建 | Intro | 无 |
| Intro | Loading | Flowing | 点击开始/自动开始 |
| Flowing | Intro、Resolving、Revive | ShotFlight、Paused、Won、Lost | 瞄准、发射、交换、道具 |
| ShotFlight | Flowing | Resolving、Flowing、Paused、Lost | 禁止第二发，交换禁用 |
| Resolving | ShotFlight、Resolving | Flowing、Paused、Won、Lost | 禁止发射 |
| Paused | Flowing、ShotFlight、Resolving | 原状态、Restart、Exit | 弹窗按钮 |
| Won | Flowing、Resolving | Result | 无 |
| Lost | Flowing、ShotFlight、Resolving | Revive、Result | 无 |
| Revive | Lost | Flowing | 无 |

- `Frenzy` 是持续 4 秒的会话修饰状态，不是阻断发射的独占状态；在 Flowing 中仍可正常瞄准发射。
- Source 生成是 Flowing 内的系统行为，不是第二条独立猫链。
- 状态切换必须由唯一 `GameSession` 管理，UI 不直接修改状态。
- 切后台自动进入 Paused；恢复前不移动队伍。
- 广告播放前保存局内快照；广告关闭后根据回调进入 Revive 或保持 Lost。

## 5. 核心规则确定值

### 5.1 猫咪与轨道

- 每关恰好一个 `Source`、一条开放且无分叉的 `Track`、一个玩法区正中央的 `Launcher` 和一个单入口 `Lair`。
- 猫只从 `Source` 的 `s=0` 出现并沿 `+s` 移动；`Lair` 只绑定 `s=L`；`Launcher` 不绑定任何轨道端点。
- 猫咪直径：1～20 关 64px，21～100 关 56px。
- 正常队列中心间距：1～20 关 66px，21～100 关 58px。
- 发射物速度：1200px/s。
- 发射/队列猫碰撞半径：1～20 关 30px/32px，21～100 关 28px/28px。
- 瞄准线最大长度：420px，遇到轨道猫时在首个预计碰撞点结束。
- 轨道起点为 0，终点为 `pathLength`；越靠近终点，距离值越大。
- 队列数组按轨道距离从大到小排列，索引 0 始终是最靠近终点的猫。
- 碰撞点投影到轨道后，按投影距离插入有序数组，禁止依赖刚体挤压决定顺序。

### 5.2 匹配与连锁

- 普通猫需要连续 3 只或更多同 `catType` 才匹配。
- 彩虹猫与接触侧的普通猫同色；两侧颜色不同则选择可形成更大匹配的一侧，相同数量时选择靠近终点的一侧。
- 单次匹配移除完整连续段，不只移除 3 只。
- 匹配动画锁定 0.18 秒，回窝飞行动画 0.42 秒，可与后续回吸部分重叠。
- 消除产生断口后，两侧边界猫同品种时，老巢侧链段以基础速度 2.2 倍向入口方向回吸。
- 不同品种时入口侧链段额外增加 160px/s 追赶速度，断口最多保留 2.4 秒，期间允许穿缝射击。
- 回吸接触后再次检测接缝匹配；每次接缝匹配令 `chainDepth + 1`。
- 解决链期间不生成新猫、不移动整条队伍、不接受发射。

### 5.3 计分

`matchScore = removedCount × 100 × chainMultiplier`

`chainMultiplier = min(1 + (chainDepth - 1) × 0.5, 4)`

- `chainDepth` 初始为 1。
- 4 只及以上的额外奖励已经包含在 `removedCount` 中，不另设复杂公式。
- 呼噜暴走不直接移除猫；暴走期间有效消除仍按正常连锁计分。
- 道具直接移除每只猫计 20 分，不增加呼噜值，不计连锁倍率。
- 最终分数为整数，显示时使用千位分隔。

### 5.4 呼噜值

`purrGain = removedCount × 8 + max(0, removedCount - 3) × 4 + max(0, chainDepth - 1) × 10`

- 呼噜槽范围 0～100，超出部分不保留。
- 第 1 关充能倍率为 1.8；若开局 30 秒仍未满，平滑补到 100。
- 第 2 关充能倍率为 1.35；若开局 45 秒仍未触发，补到 100。
- 其余关卡倍率由关卡配置决定，默认 1.0。
- 暴走持续 4 秒；猫链速度降至 55%，每次有效消除额外把链头向入口方向推回 1.5 个猫间距。
- 暴走只在 Flowing 且当前没有发射物时触发；其他情况排队到下一安全帧。

### 5.5 胜负

- 所有关卡目标均为清空本关计划生成的全部猫咪。
- `sourceClosed === true && activePieceCount === 0 && projectileCount === 0 && pendingResolveCount === 0` 时具备胜利候选条件。
- 任意链段的链头中心距离达到 `pathLength - catRadius` 时立即失败。
- 第 1 关前 20 秒对队首距离做安全钳制，最多到轨道的 70%。
- 每个逻辑帧先检查失败、再检查胜利；只有入口关闭、场上清空且没有待解析发射猫时才胜利。

## 6. 障碍与道具

### 6.1 纸箱猫

- `kind = boxed`，初始 `hp = 2`，内部保存 `hiddenCatType`。
- 不能直接匹配、不能被呼噜暴走选择。
- 紧邻纸箱猫的连续段被消除时扣 1 HP；同一次消除最多扣 1。
- HP 为 0 时播放 0.35 秒开箱动画，转为内部普通猫，再执行一次局部匹配检查。

### 6.2 灰扑扑猫

- `kind = dusty`，初始 `hp = 1`，内部保存 `hiddenCatType`。
- 相邻连续段被消除或受到猫薄荷影响后揭示。
- 未揭示前不参与普通匹配；揭示动画结束后允许局部匹配。

### 6.3 逗猫棒

- 进入目标选择态，点击任意队列猫直接移除。
- 可移除普通猫；作用于障碍时只造成 1 点揭示伤害。
- 取消选择不消耗数量。

### 6.4 猫薄荷

- 点击轨道猫作为中心，选择它及数组前后各 2 只，共最多 5 个目标。
- 普通猫直接回窝；障碍受到 1 点揭示伤害。
- 不触发呼噜值，但清除后的接缝可以触发正常连锁。

### 6.5 彩虹猫

- 使用后将当前发射猫替换为彩虹猫，不改变下一只猫。
- 若没有可匹配方向，彩虹猫以独立类型插入，直到后续普通猫使其可归属。

## 7. 星级与奖励

每关配置 `score2Star` 和 `score3Star`：

- 通关必得 1 星。
- 分数达到 `score2Star` 得 2 星。
- 分数达到 `score3Star` 得 3 星。
- 历史星级只升不降。

基础小鱼干：`20 + levelId × 2 + stars × 10`。

- 首次通关额外 30 小鱼干。
- 激励翻倍只翻倍基础小鱼干，不翻首次奖励。
- 结算发奖采用幂等 `rewardTransactionId`，重复回调不能重复发奖。

## 8. 图鉴与外观

- 12 张卡片按累计星星数解锁：3、6、9、12、15、18、21、24、30、36、48、60。
- 卡片包含名称、品种、短句、稀有度、插画和是否已查看。
- 前 5 张对应基础猫；后 7 张是表情或主题外观，不新增可匹配类型。
- 外观价格档位：免费、150、300、500 小鱼干。
- 购买后永久拥有；一次只能应用一个猫窝和一个拖尾。
- 购买、应用、解锁均立即保存。

## 9. 广告与分享

### 9.1 激励广告

- 前五关不主动展示广告按钮；失败页保留复活位但第 1～5 关提供一次免费复活，不调用广告。
- 第 6 关起，单局广告复活次数不限：每次失败均可主动选择观看一次激励广告并复活，再次失败仍保留相同入口；不能因为 `reviveCount > 0` 禁用。
- 每次广告会话使用独立 `adAttemptId` 和复活事务 ID。同次回调幂等、新的有效广告会话可再次发奖；不得用“本局已复活”作为幂等键。
- 播放广告前保存对应失败快照并暂停局内计时；取消、失败、无填充回到该快照，不发奖、不递增成功复活次数；免费重开/退出可选。
- 游戏内不限制复活次数，但不能承诺第三方广告永远有填充；平台未提供广告时必须给出真实可恢复反馈。
- 广告未加载：按钮显示“暂时没有视频”，2 秒后恢复可点击重试。
- 广告未看完：不发奖励，返回原页面并提示“看完才能领取哦”。
- 广告看完：写入幂等记录后发奖。

### 9.2 自动录屏

- 进入 Playing 时开始录屏，结算前停止。
- 优先裁取结束前 20～25 秒。
- 低于平台最短可分享时长时隐藏录屏分享按钮，保留普通图文分享。
- 每段录屏的分享奖励最多领取一次。

## 10. 设置与存档

默认设置：音乐开、音效开、震动开。

存档至少包含：

- schemaVersion
- highestUnlockedLevel
- bestStarsByLevel
- bestScoreByLevel
- fishBalance
- ownedCosmetics
- equippedCosmetics
- boosterCounts
- unlockedCards
- seenCards
- settings
- consecutiveFailuresByLevel
- rewardedTransactions

本地写入成功后才更新界面余额。云存档不可用时继续使用本地存档并提示，不阻塞游戏。

## 11. 固定文案语气

- 使用“贴贴”“回窝”“收编”“猫猫队伍”。
- 禁止使用“消灭猫”“炸死”“击杀”“尸体”等表达。
- 操作提示每次不超过 14 个汉字。
- 错误提示说明发生了什么以及用户下一步可以做什么。

关键文案：

| 场景 | 文案 |
|---|---|
| 首次发射 | 松手，把猫猫送去贴贴 |
| 交换教学 | 点一下猫窝，交换猫猫 |
| 呼噜满 | 呼噜值满啦！ |
| 暴走 | 呼噜暴走！猫步慢下来！ |
| 普通失败 | 罐头仓库挤满啦 |
| 广告不可用 | 暂时没有视频，先重试这一关吧 |
| 离线 | 网络开小差，进度已保存在本机 |

- `app_ready`
- `home_view`
- `level_prepare`
- `level_start`
- `tutorial_step`
- `level_end`
- `purr_frenzy`
- `booster_use`
- `revive_offer`
- `rewarded_ad_result`
- `share_click`
- `share_result`
