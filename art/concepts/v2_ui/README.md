## 生成与质量记录

- 使用内置 `image_gen.imagegen`，本会话工具不暴露模型选择或后端模型标识；不能核实为 `gpt-image-2`，未使用付费 API。
- 复用 `art/concepts/c02_core_screens_board.png` 的画风和 `c03_five_cats_character_board.png` 的五猫身份。
- 100 关必须分别引用当前 `design/track-review/catalog.source.json` 的几何与哈希，不允许图片生成擅改轨道。
- 每个独立页面/关卡分别生成；组件状态板可以在同一图内比较同一组件的多个状态，不冒充独立页面。
- `candidate` 为待自检或需要返工，不能作为自动通过凭据。图中中文、位置和安全区仍须逐张检查。
- ImageGen 图不具备可编辑文字和组件，不能替代后续 V2 Figma 重建；本轮不开始 Cocos 重构。
