# UI-07 引擎截图

2026-09-15，真实Cocos Canvas截图。`build/`来自最终独立静态包，`editor/`来自用户工程编辑器预览。审查场景复用原五猫/UI纹理；不是生成概念图，也不是动态玩法录像。

- `build/360/L001.png`～`L100.png`：360×640、模拟安全区、末段猫链。
- `build/390/L001.png`～`L100.png`：390×844、模拟安全区、中段猫链。
- `build/430/L001.png`～`L100.png`：430×932、模拟安全区、开段猫链。
- 每个尺寸另外有 `obstacle-hp1.png`、`obstacle-revealed.png`：第100关的纸箱一次受损、揭示状态。
- `editor/390/`：同一场景在编辑器中的百关截图与两个额外状态。
- `contact/levels-001-020.jpg` 等五张总览来自390宽度原截图的等比例缩小；用于检查总体遮挡，不替代原尺寸文字和细节检查。
- `initial.png`为跨日恢复时的空白页截图，保留失败记录；`initial-loaded.png`才是随后实际加载成功的首屏。两者均不计入逐关验收。

当前障碍是明确标注的压力试样，可在第一章手动显示，不能据此认为第一章正式加入障碍。UI、设施方向与轨道完整性在截图和静态计算中核对；手机细表情、动态障碍变化、真实抖音安全区与上线质量仍未验收。
